# Inventory Analytics Dashboard

A beginner-friendly analytics project that demonstrates how to clean, summarize, and visualize operational inventory data in Excel.

## What this project shows
- Building a clean raw-data table
- Calculating inventory value with formulas
- Flagging items below reorder point
- Summarizing trends by category
- Creating a dashboard with KPI cards and charts

## Files
- `inventory_data.csv` — sample inventory dataset
- `inventory_dashboard.xlsx` — Excel dashboard with formulas and charts

## Business question
How can a small operations team quickly identify stock value, reorder risk, and category-level inventory trends?

## Skills demonstrated
Excel, data cleaning, KPI tracking, formulas, basic dashboard design, operational analytics
